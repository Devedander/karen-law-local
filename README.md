# Karen Webb Law website

A framework-free, responsive rebuild of the public Karen Webb Law site. It preserves the live site's four-page content model, current page copy, contact details, bar and broker credentials, practice areas, imagery, full terms/privacy text, and legal advertising disclaimer while presenting them in a distinct “case notebook” layout.

Open `index.html` directly or serve this folder with any static web server. The contact form uses the same visitor fields as the live form and opens a pre-addressed email draft because the live WordPress/Gravity Forms backend cannot run from a static local file.

The visual system uses coastal blue, clear white space, restrained coral action cues, editorial serif headings, and compact notebook-like practice sections. This direction is intentionally different from the photo-led historic-inn design used for Duncans Mills House.
